# Undangan Edu Fair & Career Day 2026 - SMKN 6 Tangerang Selatan

Aplikasi web undangan digital interaktif dan personal untuk acara **Edu Fair & Career Day 2026** di SMKN 6 Kota Tangerang Selatan, dilengkapi dengan sistem konfirmasi kehadiran (**RSVP**) yang terhubung ke basis data cloud **Supabase (PostgreSQL)** secara aman.

---

## 🔒 Panduan Keamanan GitHub (Sangat Penting!)

Agar proyek ini **100% aman saat di-push ke GitHub** tanpa risiko kebocoran data:

1. **File Kredensial Sensitif Sudah Diabaikan (`.gitignore`):**
   - File `.env` (berisi password database PostgreSQL dan `supabase_private_key`) **tidak akan ikut terunggah** ke repositori publik GitHub.
   - Folder `node_modules/` juga otomatis diabaikan.

2. **Perbedaan Key di Supabase:**
   - **Publishable Key (`sb_publishable_...`)**: Kunci ini aman digunakan di sisi *frontend* browser (`config.js`) karena hak aksesnya dijaga ketat oleh fitur **Row Level Security (RLS)** pada tabel Supabase.
   - **Secret Key (`sb_secret_...`) & Database Password**: Kunci ini **HANYA** boleh berada di sisi server (`.env`) dan **TIDAK PERNAH** dimasukkan ke kode HTML/JS publik di browser.

3. **Template Contoh untuk GitHub:**
   - Tersedia `.env.example` dan `config.example.js` yang berisi placeholder. Jika orang lain melakukan `git clone`, mereka tinggal menduplikasi file tersebut dan mengisi kredensial mereka sendiri.

## 🗄️ Konfigurasi Basis Data Supabase

Tabel yang digunakan pada Supabase PostgreSQL adalah `public.konfirmasi_kehadiran`:

```sql
CREATE TABLE public.konfirmasi_kehadiran (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    tamu_id BIGINT,
    nama TEXT NOT NULL,
    instansi TEXT,
    kategori TEXT,
    konfirmasi TEXT NOT NULL,
    tanggal TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- Mengaktifkan Row Level Security (RLS)
ALTER TABLE public.konfirmasi_kehadiran ENABLE ROW LEVEL SECURITY;

-- Hak Akses (RLS Policy) Publik untuk Mengirim RSVP
CREATE POLICY "Allow public insert" 
ON public.konfirmasi_kehadiran 
FOR INSERT 
TO anon, authenticated, service_role
WITH CHECK (true);

-- Hak Akses (RLS Policy) Publik untuk Membaca RSVP di Admin
CREATE POLICY "Allow public select" 
ON public.konfirmasi_kehadiran 
FOR SELECT 
TO anon, authenticated, service_role
USING (true);
```

## 🚀 Cara Menjalankan Proyek

Anda dapat menjalankan proyek ini dengan **2 cara mudah**:

### Cara 1: Menggunakan Live Server (VS Code) — Paling Praktis
1. Buka folder proyek ini di **Visual Studio Code**.
2. Klik kanan pada `index.html` lalu pilih **Open with Live Server**.
3. Buka juga `admin.html` dengan Live Server untuk melihat dashboard admin.
4. RSVP akan langsung terhubung ke Supabase melalui client SDK.

### Cara 2: Menggunakan Server Node.js
1. Buka terminal di folder proyek ini.
2. Jalankan perintah instalasi dependensi (hanya perlu sekali):
   ```bash
   npm install
   ```
3. Jalankan server:
   ```bash
   npm start
   ```
4. Buka browser:
   - Undangan: [http://localhost:3000](http://localhost:3000)
   - Admin: [http://localhost:3000/admin.html](http://localhost:3000/admin.html)

## 💡 Fitur Utama

1. **Personalisasi Undangan Otomatis:**
   - Link undangan yang dikirimkan via WhatsApp memuat parameter nama, instansi, dan kategori tamu (misal: `index.html?nama=Syifa&instansi=SMKN+6&kategori=Siswi`).
   - Halaman secara otomatis menyapa tamu tersebut secara personal dan mengunci nama pada form RSVP.
   - Jika pengunjung membuka tanpa link personal, pengunjung tetap dapat mengetikkan nama dan instansi secara manual.

2. **Formulir RSVP Real-Time:**
   - Pilihan: **Hadir** atau **Tidak Hadir**.
   - Dilengkapi validasi form, indikator status loading (*"Menyimpan ke database..."*), dan pesan konfirmasi yang jelas.
   - Data otomatis tersimpan ke tabel `konfirmasi_kehadiran` di Supabase.

3. **Dashboard Admin Lengkap:**
   - Kartu statistik: Total Konfirmasi, Jumlah Hadir, Jumlah Tidak Hadir, Total Tamu CSV.
   - Tabel Data RSVP langsung dari database Supabase (dilengkapi tombol Refresh dan fitur pencarian nama/instansi).
   - Generator pesan WhatsApp otomatis dengan format rapi dan tautan personal untuk setiap tamu di `data-tamu.csv`.
